Google Sheets — Live Data Sync

PIN-protected Google Sheets connection

This panel and manual sync controls require the existing Manager PIN. Change the Manager PIN from Manager’s Tab. Once configured, automatic background sync continues after recorded changes so reporting stays current.

What will sync?

Completed transactions, item-by-item sales, menu catalog, inventory, and audit history. Columns are named in plain language. Transaction and audit records include the actual date and time, stored in ISO format and displayed in Asia/Manila time in the sheet. PINs are never sent.

This POS saves locally first. After you connect a Google Apps Script web app, it sends an updated data snapshot whenever a sale, audit entry, menu, or inventory change occurs. If unsynced changes remain when you close the tab, the browser may show its standard leave-page warning and the POS queues a best-effort transfer during shutdown. Browsers cannot guarantee shutdown delivery.

Not connected. Add the deployed Apps Script URL to enable syncing.

Setup required once

  1. Create a Google Sheet.
  2. Open Extensions → Apps Script, paste the companion script provided with this POS, and save.
  3. Deploy → New deployment → Web app; execute as you, and grant access as appropriate for your store.
  4. Copy the web app URL ending in /exec here and choose Save Connection.

Treat the web app URL as private. Anyone who obtains a publicly accessible endpoint may be able to submit data to your sheet; restrict access and test with a separate sheet first.
