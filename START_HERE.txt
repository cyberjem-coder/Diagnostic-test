MENU 502 DIAGNOSTICS
The mobile-menu function returns a safe diagnostic stage, error type, code, and
provider HTTP status when an operation fails. The cashier status message displays
these fields. Look for:
- stage=cashier_authorization_storage
- stage=menu_storage_write
- stage=menu_storage_read
An incident ID is also provided. Send the diagnostic text and incident ID for
troubleshooting, but never send private keys or tokens.

This diagnostic feature helps identify the failure; it does not guarantee that
Netlify or its storage provider can never have an outage.
